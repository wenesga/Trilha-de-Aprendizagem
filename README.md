# 🎓 Trilha de Aprendizagem

Gamificação no ensino de Estatística do Ensino Médio: o aluno estuda a teoria, responde às missões, ganha XP e o professor acompanha o acerto da turma em cada habilidade da BNCC.

---

## ✨ O que ele faz

- 📊 **Seis conteúdos de Estatística**, com 44 missões, cada um ligado a uma habilidade da BNCC.
- 🎮 **Missões com correção na hora** e **XP**, que diminui um pouco a cada erro, sem nunca zerar.
- 🏆 **Placar da Turma**, com o apelido e o XP de cada aluno.
- 🛡️ **Painel do Professor**: desempenho da turma, acerto de cada aluno em cada habilidade e relatório em PDF por conteúdo.
- ➕ **Conteúdos novos**, cadastrados pelo professor, com a habilidade escolhida numa lista pesquisável.

## 🚀 Como rodar

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\streamlit run trilha_aprendizagem.py
```

🔑 Senha padrão do Painel do Professor: `computa258`. *Troque em Configurações.*
